Why Shelf

A polished writing surface — without the cloud lock-in

Shelf is for students, researchers, and anyone who reads a lot of PDFs and wants their notes, sources, and annotations stored locally in an open, exportable format.

📝

A real editor

Slash commands, headings, checklists, code blocks, KaTeX formulas, quotes, tables, images, video, and drag-and-drop blocks.

📚

A real PDF workflow

Read a source and write the linked note side by side. Position, zoom, and layout are remembered per document.

🔎

Find anything fast

Press ⌘K to search titles and full page content, and jump straight to recent pages.

📦

Portable by default

Export any page or page tree as Markdown or JSON. Your database is backed up automatically before every update.

Studio

Read and write in one place

Import a PDF and Shelf pairs it with a linked note in a split workspace. Everything you read and everything you write stays together — and stays local.

  • Page through with arrow keys or trackpad swipes.
  • Continuous, single, and two-page reading modes.
  • Viewer state — position, zoom, layout — is remembered per document.
  • Flat memory use, even in 800-page documents.

Tour

The whole workspace

Editor, Studio, search, and home dashboard — Shelf follows your system theme or your explicit choice.

Privacy model

No account. No cloud. No telemetry.

Shelf has no account system and no cloud backend. Everything lives in SQLite on your machine, in formats you can export at any time.

0accounts required
0cloud servers
0telemetry requests
100%local-first by design

Build artifacts never include your personal database — an installed build starts from that computer's own empty workspace. Signed update manifests and SHA-256 checks keep assisted updates tied to official Shelf releases.

PlatformFileNotes

On macOS, Gatekeeper may warn about an unidentified developer — the build is hardened-runtime but not notarized yet. On Windows, SmartScreen may warn on first run — choose More info → Run anyway. Signing and notarization are tracked openly in the repository.
