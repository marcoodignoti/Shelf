# Shelf v0.3.1

Shelf `v0.3.1` is a hotfix for legacy installed databases.

## Changes

- Fixed startup with older Studio PDF databases whose `studio_documents` table did not yet have `title` and `note_page_id` columns.
- Preserves existing installed data by deriving missing Studio document metadata from the linked page and original PDF filename.

## Tester Notes

This update is intended for users whose installed app process starts but the window fails to open after the Shelf migration.
