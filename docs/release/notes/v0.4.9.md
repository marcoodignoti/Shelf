# Shelf v0.4.9

Shelf `v0.4.9` brings a modernized titlebar experience for Windows users, a redesign of the external assistant popover, and a fully polished landing page.

## Changes

- **Modern Windows Titlebar & Custom Controls**:
  - Removed the native `titleBarOverlay` click dead zone, replacing it with a fully styled custom HTML titlebar.
  - Reworked window drag regions to ensure the sidebar toggle and window controls are always fully clickable without overlap.
  - Compacted the left UI on Windows for a cleaner native feel without unnecessary offsets.

- **External Assistant Redesign**:
  - Redesigned the assistant popover and used non-focus-stealing activation (`showInactive`) to let you interact seamlessly with it.
  - Fixed test mock behaviors for the window focus cycle.

- **Landing Page Redesign**:
  - Simplified the visual layout using a minimal Cron/Linear-style editorial look.
  - Inlined the product demo video directly into the Studio room media frame.
  - Set up a self-hosted, subsetted Inter variable font to optimize performance.
