# OpenNotion v0.1.8

OpenNotion `v0.1.8` adds keyboard and swipe page navigation to the Studio PDF
viewer, makes page changes seamless, and introduces restart-to-update on
Windows installer builds.

## Changes

- The Studio PDF viewer pages with the left/right arrow keys, trackpad
  horizontal swipes, and touch swipes in the paged view modes. Arrow keys
  never steal caret movement from text inputs.
- Changing pages no longer flashes a blank canvas: the next page renders
  off-screen and replaces the previous one only when it is ready.
- The PDF document is no longer destroyed and re-parsed on every page change
  (and no longer loads twice when a document opens), making page navigation
  much lighter on large PDFs.
- Wheel-swipe page turns now work with classic always-visible scrollbars
  (Windows, or macOS with "Show scroll bars: Always"); the right-edge
  detection previously never triggered there.
- Windows installer builds show a "Restart to update" notice once an update
  has downloaded in the background; dismissing it keeps the current
  install-on-quit behavior. Installer builds no longer show a second,
  manifest-based update prompt on top of the automatic one.

## Tester Notes

Existing notes, Studio documents, and settings are untouched; no data
migration is required. macOS and portable Windows builds keep the in-app
download notice: restart-to-update requires the installer pipeline (and on
macOS a signed build, which the beta does not ship yet).
