# OpenNotion v0.2.2

OpenNotion `v0.2.2` is a small follow-up to `v0.2.1` that finishes the move
from beta-tester positioning to a public release.

## Changes

- Updates now present themselves as the stable channel: the Settings section
  and the update notice no longer talk about beta builds, in both English
  and Italian.
- The About section gains a "Report a problem" row that opens a GitHub issue
  with the right template pre-selected.
- The README installation guide now starts with a per-platform download
  table and spells out the first-launch steps on macOS (right-click → Open)
  and Windows (SmartScreen → Run anyway).

## Tester Notes

Nothing changes on disk: notes, Studio documents, profile, and preferences
are untouched. Update checks keep working exactly as before — only the
wording changed.
