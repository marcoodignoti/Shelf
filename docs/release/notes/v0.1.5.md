# Shelf v0.1.5

Shelf `v0.1.5` fixed the Windows beta update manifest so installer downloads
were visible to the app update checker. Current builds use the signed manifest
flow for guided installer downloads instead of background installer updates.

## Changes

- Beta update manifests now include the Windows NSIS installer artifact.
- Windows update checks prefer the installer and keep the ZIP as fallback for
  legacy portable builds.
- Trusted update downloads now allow `.exe` artifacts after host, path, and hash
  verification.
- Strict manifest generation now requires DMG, ZIP, and Windows installer
  artifacts.

## Tester Notes

Existing `v0.1.4` Windows builds can still fall back to the ZIP because they do
not know the new installer manifest field. Install the Windows setup executable
once to move onto the current signed update notice path.
