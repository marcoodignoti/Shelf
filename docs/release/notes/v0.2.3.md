# Shelf v0.2.3

Shelf `v0.2.3` fixes a serious clipboard bug: copying content that
contains formulas or page links silently failed.

## Changes

- Copying a selection that includes an inline formula, a formula block, or
  a page link now actually writes to the clipboard. Before this fix the
  copy crashed internally, nothing was written, and pasting reproduced
  whatever was on the clipboard from before — which looked like copy and
  paste doing nothing at all.
- Select all (Cmd+A) now also works on pages that start or end with a
  formula or media block.
- Pasting content with inline formulas restores them as editable formulas
  instead of losing them.

## Tester Notes

No data changes. If copy/paste between Notes and Studio seemed broken for
you, this release is the fix — notes with LaTeX formulas were the trigger.
