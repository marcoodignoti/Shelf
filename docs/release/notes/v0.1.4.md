# Shelf v0.1.4

Shelf `v0.1.4` added the first Windows installer update experiment and refreshed
the release CI runtime. Current builds use the signed manifest update flow
instead.

## Changes

- Windows NSIS installer builds are now generated by CI.
- Windows installer builds were wired into GitHub Release update metadata.
- In-app update toasts reported Windows installer update availability and
  downloaded-ready state in that historical build.
- The Windows ZIP remains available for legacy portable testers.
- Release docs included the installer metadata and beta compatibility
  manifest flow.
- GitHub Actions now use Node 24-compatible action versions and a pinned
  `windows-2025` runner.

expected until Developer ID notarization and Authenticode signing are added.
