# OpenNotion v0.1.4

OpenNotion `v0.1.4` adds Windows installer auto-update support and refreshes
the release CI runtime.

## Changes

- Windows NSIS installer builds are now generated by CI.
- Windows installer builds check GitHub Releases in background, download newer
  installers automatically, and install updates on app quit.
- In-app update toasts now report Windows installer update availability and
  downloaded-ready state.
- The Windows ZIP remains available for legacy portable testers.
- Release docs now include the installer, `latest.yml`, and beta compatibility
  manifest flow.
- GitHub Actions now use Node 24-compatible action versions and a pinned
  `windows-2025` runner.

expected until Developer ID notarization and Authenticode signing are added.
