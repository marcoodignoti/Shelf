# Shelf v0.2.1

Shelf `v0.2.1` rebuilds the Settings area from the ground up: every
visible control now does something real, the whole interface speaks both
English and Italian, and the editor finally exposes typography and layout
preferences.

## Changes

- Settings is reorganized into seven sections — Profile, Preferences,
  Appearance, Shortcuts, Updates, Import / Export, and About — each fully
  functional. The decorative account entry is gone.
- The app is fully translated into Italian. A language picker (System /
  English / Italiano) switches the entire interface instantly, including
  the editor's slash menus via BlockNote's own Italian dictionary. Dates
  follow the selected language.
- A local workspace profile lives in the Profile section: display name,
  workspace name, and an avatar image (or an automatic initial). The
  profile is stored in the database, travels with JSON backups, and the
  sidebar card in Settings reflects edits live.
- Appearance gains real editor typography controls: font family (Sans,
  Serif, Mono — previewed live in the picker), text size (Small, Default,
  Large), plus the existing theme picker moved here.
- Preferences gains two new behaviors: page width (centered column or full
  width) and the title Enter key (jump to the page body, or insert a line
  break — the old static row is now a working control).
- A Shortcuts section lists every real keyboard shortcut in the app,
  grouped by area, with platform-aware modifier symbols.
- About shows the installed version, the database location with a copy
  button, and links to GitHub and the MIT license.
- Toast messages are now locale-aware, and a failed page search shows
  "Search failed." again instead of pretending there were no results.

## Tester Notes

Existing notes, Studio documents, and settings are untouched. New
preferences default to the previous behavior (centered pages, sans font,
default size, Enter moves to the body) and the language follows your
system, falling back to English. Replacing the avatar image cleans up the
previous file on disk.
