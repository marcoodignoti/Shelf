# Shelf v0.3.2

Shelf `v0.3.2` is a hotfix for unified Studio PDF deletion.

## Changes

- Fixed deleting an imported PDF from the private page tree so it deletes the Studio document instead of trying to delete its primary note directly.
- Keeps navigation on a valid page after deleting a Studio document.

## Tester Notes

Use this update if deleting an imported PDF showed `delete the Studio document before deleting its primary note`.
