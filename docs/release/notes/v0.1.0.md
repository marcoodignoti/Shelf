# OpenNotion v0.1.0

OpenNotion `v0.1.0` is the first public desktop release.

This release includes the RC3 fixes validated on macOS and Windows.

## Included

- Local-first Notion-style desktop notes backed by SQLite.
- Pages, subpages, favorites, icons, search, slash commands, structured blocks,
  formulas, code, lists, checklists, and drag/drop organization.
- Studio mode for importing local PDFs and writing linked notes side by side.
- Local media, covers, editor images, and Studio documents stored in app data.
- macOS unsigned DMG for Apple Silicon.
- Windows unsigned portable x64 zip.

## Fixed Since RC2

- Editing an existing formula block no longer jumps the page scroll to the
  bottom of long documents.
- Browser spellcheck, autocorrect, and autocapitalization are disabled inside
  the editor surface to avoid red spelling underlines in notes and formulas.
- Windows portable build uses the OpenNotion app icon instead of the stock
  Electron executable icon.

## Validation

- RC3 manual validation passed on Windows.
- GitHub Actions CI passed on commit `5ea54dbb43326275f10f53d52fc66b63eb40d173`.
- Local macOS package verification passed for the release DMG.

## Known Limitations

- macOS build is unsigned/ad-hoc and not notarized.
- Windows build is unsigned and may trigger SmartScreen.
- Windows artifact is a portable zip, not an installer.
- No cloud sync or account system is included.
