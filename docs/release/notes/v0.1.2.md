# Shelf v0.1.2

Shelf `v0.1.2` is a beta stabilization release focused on update delivery,
slash command discovery, and tester install paths.

## Changes

- Beta updates now check a stable `beta` channel manifest before falling back to
  the GitHub latest-release manifest.
- Update notices guide testers through manual DMG/ZIP installation and show a
  Homebrew command on macOS.
- Added a Homebrew Cask beta tap template and release checklist.
- Slash command search now keeps global ranking stable and avoids weak
  one-letter contains matches.
- The editor arrow-navigation E2E test now asserts the selected block more
  directly.
- Local file URLs and Studio PDF responses now use tighter trust checks for the
  Electron renderer.
- Backup imports sanitize unsafe cover and media URLs before saving imported
  pages.
