# OpenNotion v0.1.0-rc.1

OpenNotion `v0.1.0-rc.1` is the first public release candidate for the
Electron desktop app.

## What's Included

- Local-first notes workspace backed by SQLite.
- Notion-inspired editor with pages, subpages, favorites, search, slash
  commands, formulas, local images, and Trash flows.
- Studio mode for importing local PDFs and writing linked notes side by side.
- Unsigned macOS DMG for private testing.
- Unsigned Windows portable zip from GitHub Actions.
- Public-ready repository documentation, MIT license, third-party notices,
  contributing guide, and security policy.

## Known Limitations

- macOS build is unsigned/ad-hoc and not notarized.
- Windows build is unsigned and may trigger SmartScreen.
- Windows artifact is a portable zip, not an installer.
- No hosted sync or account system.
