# Shelf v0.3.0

Shelf `v0.3.0` is the rename and workspace redesign release.

## Changes

- The app is now Shelf across product metadata, release assets, docs, Homebrew cask, update manifests, and repository links.
- The sidebar now uses a transparent macOS-style material, fixed bottom settings entry, stronger hover states, and hidden native scrollbars while keeping scroll behavior.
- Studio PDFs and editor surfaces keep an opaque reading surface so transparent chrome does not damage text readability.
- Settings/profile avatar imports now load from app-managed storage without crashing.
- Studio notes are integrated into the main page tree instead of a separate Studio sidebar.

## Tester Notes

Existing local data is preserved: Shelf still reads the legacy
`org.opennotion.desktop/opennotion.db` location and old app-managed asset URLs.
