# Shelf v0.4.0

Shelf `v0.4.0` introduces project/folder organization in the sidebar, local WebAssembly PDF asset loading in Studio, UI styling improvements, and security hardening.

## Changes

- **Projects Management**: Group and organize pages into projects/folders directly from the sidebar. Support for project creation, renaming, deletion, nesting, and moving pages between projects.
- **Studio Improvements**: Load PDF WebAssembly assets locally to speed up rendering and reliability of the document viewer.
- **Sidebar & UI Polish**: Renamed the "Private" section to "Pages" and refreshed the layout with modern aesthetics, clean borders, and better spacing.
- **Security Hardening**: Hardened desktop update mechanisms and file IPC bridge security.
- **Performance Optimizations**: 
  - Reduced page tree traversal complexities from quadratic $O(n²)$ to linear $O(n)$ for sidebar visible page lookups, descendant scans, and page move validation checks.
  - Eliminated redundant page re-renders in the Sidebar and Command Palette by wrapping Zustand store selectors in `useShallow`.
  - Optimized SQLite page updates by executing a single dynamic statement instead of multiple sequential single-column writes in a transaction.
  - Drastically reduced Electron IPC payload size by omitting full page text/search content when querying Studio PDF page links.
  - Bypassed costly JSON parsing/exception handling on plain text search results during page preview queries.
  - Optimized database rows sorting using a pre-computed sort key Map, dropping JSON parsing complexity from $O(n \log n)$ to $O(n)$.
- **Bug Fixes & Refinement**: Added missing translations for sidebar context menus, resolved page creation flow edge cases, and expanded the E2E test suite.
