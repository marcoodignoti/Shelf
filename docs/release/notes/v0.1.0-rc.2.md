# OpenNotion v0.1.0-rc.2

OpenNotion `v0.1.0-rc.2` is a Windows packaging fix release candidate.

## Fixed

- Windows portable build now patches `OpenNotion.exe` with the OpenNotion app
  icon instead of leaving the stock Electron executable icon.
- Windows executable metadata now uses OpenNotion product and file descriptions.

## Artifacts

```text
OpenNotion_0.1.0_arm64.dmg
OpenNotion_0.1.0_win-x64.zip
```

## Known Limitations

- macOS build is unsigned/ad-hoc and not notarized.
- Windows build is unsigned and may trigger SmartScreen.
- Windows artifact is a portable zip, not an installer.
