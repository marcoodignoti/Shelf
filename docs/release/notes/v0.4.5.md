# Shelf v0.4.5

Shelf `v0.4.5` is a visual polish release for the floating main card, sidebar
chrome, and Studio split surface.

## Changes

- **Floating main card refinement**:
  - The main workspace now reads as a rounded card with a transparent gutter and
    a consistent subtle border around the Notes and Studio surfaces.
  - Header borders now close cleanly around the top and bottom edges, including
    the Studio PDF toolbar.

- **Sidebar and titlebar alignment**:
  - macOS traffic lights, the sidebar toggle, and breadcrumbs are vertically and
    horizontally aligned with the floating main card.
  - Sidebar navigation has more breathing room below the traffic lights and
    better left-column alignment.

- **Sidebar resizing**:
  - Resizing now happens from the main card's left edge instead of a visible
    divider inside the sidebar.
  - The resize handle is invisible until used, preserving the clean gutter.

- **Settings window cleanup**:
  - Embedded Settings no longer duplicate macOS window controls or the close
    button when opened as a full-screen app surface.

## Tester Notes

Open Notes and Studio with the sidebar both open and closed. Verify the gutter,
main card border, breadcrumbs, sidebar toggle, and traffic lights feel aligned.
Resize the sidebar from the left edge of the main card and confirm no visible
vertical divider appears.
