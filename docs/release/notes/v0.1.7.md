# Shelf v0.1.7

Shelf `v0.1.7` fixes an app freeze when creating checklists and makes
editing, PDF reading, and local data handling faster and more robust.

## Changes

- Creating a checklist no longer freezes the app (infinite DOM mutation loop
  between the spellcheck observer and the ProseMirror checkbox node view).
- Typing is lighter: the editor no longer serializes the whole document and
  updates the global page store on every keystroke; both now happen once per
  debounced save.
- Long PDFs in continuous mode release off-screen page bitmaps, keeping memory
  bounded instead of accumulating every page ever scrolled past.
- SQLite startup now uses a busy timeout, schema migrations run atomically, and
  backup exports are written atomically so interrupted writes cannot corrupt
  the backup file.
- The Studio PDF server now requires a trusted Origin on all requests, and
  editor media drag and drop reports import errors clearly.

## Tester Notes

Existing notes, Studio documents, and settings are untouched; no data
migration is required. If editing a media-heavy or formula-heavy page felt
sluggish in `v0.1.6`, it should feel noticeably lighter now.
