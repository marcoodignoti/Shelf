# Shelf v0.1.1

Shelf `v0.1.1` is a private beta update focused on Studio reliability,
shared notes, and tester update delivery.

## Changes

- Studio PDFs can be linked to multiple pages and page-specific bookmark notes.
- Studio notes are available from the main Notes workspace and shared search.
- Inline page links support page previews and custom labels.
- Slash command search, popover sizing, and keyboard navigation are more stable.
- Large PDF imports avoid main-window freezes and continuous PDF view mounts fewer pages.
- Dark mode editor text and breadcrumb readability are improved.
- Beta update notices now show a short changelog and open manual downloads.
